# NEXORA brand system

## Identity
NEXORA — Stellar Financial Terminal

Tagline: Discover. Analyze. Execute.

## Palette
- Graphite background: `#0D1410`
- Graphite surface: `#121C16`
- Emerald: `#10B981`
- Emerald light: `#34D399`
- Mint: `#D1FAE5`
- Light canvas: `#F5F8F5`

No blue-led visual identity. Emerald is reserved for primary actions, positive states and selected navigation.

## Themes
Support both dark and light modes. Maintain WCAG-aware contrast, visible focus rings and clear disabled states.

## UI principles
- Premium fintech terminal, dense but readable.
- Consistent spacing, typography and compact data tables.
- Responsive from mobile to desktop.
- Display explicit labels for sample, delayed, estimated and live data.
- Never imply that a preview control is a functioning financial action.
